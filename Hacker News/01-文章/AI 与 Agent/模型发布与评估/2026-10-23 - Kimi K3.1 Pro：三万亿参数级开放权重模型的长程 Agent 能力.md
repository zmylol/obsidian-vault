# Kimi K3.1 Pro：三万亿参数级开放权重模型的长程 Agent 能力

<!-- AUTO:BEGIN -->
## 摘要

Kimi 发布 K3.1 Pro 与 Highspeed 版本：前者是三万亿参数级开放权重模型，提供一百万 token 上下文；后者主打 2–3 倍交互速度。官方把重点放在大规模后训练、长程编码、三维建模、金融研究和 Agent 工作流，并计划在 11 月 4 日发布完整权重。

## 重点解读

- K3.1 Pro 是 K3 的后训练版本，发布方称为跨数百下游领域联合强化学习优化了 RL 框架、长上下文推理、训练效率、沙箱和 rollout 调度。
- 官方报告 Terminal-Bench 4.0 得分 65.7%，Kimi Code Bench 3.0 Long-horizon 得分 61.2%；这些是发布方基准，不是独立复测。
- 文章展示了从代码修复、游戏和 Three.js，到 3D CAD、Blender、金融建模与研究的案例；其中一个内部实验让人体行走模拟器从数秒崩溃改到连续交替步行 11.2 秒。
- 官方还讨论网络安全能力控制：开放权重版本有意低于其内部可达到的攻击能力，并把逐步开放与防御审计联系起来。

## HN 讨论

HN 评论集中讨论基准是否可信、Artificial Analysis 排名与实际体验的差异、订阅限额和价格；也有讨论担心减少网络安全后训练会导致模型写出不安全软件。这些是社区观点。

## 局限与待核验

主要数字来自 Kimi 自有基准和内部案例，未独立复现；完整权重尚未在本轮验证，价格、限额和发布日期可能变化。
