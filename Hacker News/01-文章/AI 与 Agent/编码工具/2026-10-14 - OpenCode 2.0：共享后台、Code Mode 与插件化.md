# OpenCode 2.0：共享后台、Code Mode 与插件化

<!-- AUTO:BEGIN -->
## 摘要

OpenCode 2.0 将共享后台服务作为默认架构，并围绕可编程 API、工具组合、后台任务与插件热加载扩展编码 Agent。TUI、网页和桌面客户端可共享服务，但重写的 API、插件及内部模块也带来明显的升级兼容成本。

## 重点解读

- 不同客户端连接同一后台进程，程序客户端可自动发现服务。
- 新版 API 让 Agent 能调用自身接口管理会话和 worktree。
- Code Mode 把 MCP/OpenAPI 工具包装成脚本函数来组合调用，MCP 服务默认采用此模式。
- 子 Agent 和 shell 命令支持后台运行，主会话可继续工作。
- 内部功能大量插件化并支持热加载，SDK 可嵌入其他环境；旧插件与服务器 API 不兼容。

## HN 讨论

HN 评论肯定多客户端和后台任务，也质疑安装器性能、网页交互与热加载安全。有用户报告只隔离 TUI 时后台服务调用未受原沙箱约束，属于未独立复现的社区报告。
