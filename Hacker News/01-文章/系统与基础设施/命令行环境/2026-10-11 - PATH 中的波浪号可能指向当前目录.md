# PATH 中的波浪号可能指向当前目录

<!-- AUTO:BEGIN -->
## 摘要

作者由沙箱工具的警告发现：双引号包住的 PATH 赋值中，字面量 ~ 不会展开为用户主目录。这样的路径项会被当作相对路径，使命令搜索落到当前目录下的 ~/ 子目录；原文用小程序展示了这一行为。

## 重点解读

- 问题来自把 ~/.local/bin 写入整体双引号包住的 PATH 字符串，波浪号因此保留为普通字符。
- 原文建议在带引号的赋值中使用 $HOME 表示主目录；它也说明未引用赋值中的展开规则不同。
- 演示在当前目录建立字面量 ~ 子目录并从中找到命令，最后给出检查 PATH 是否含 ~ 的方法。

## HN 讨论

HN 讨论细辨变量赋值与普通命令参数的展开规则，并纠正了若干引用方式的误解。还有关于数组、不同 shell 和 PATH 顺序的延伸讨论。

## 局限与待核验

已读正文与演示，没有执行页面命令或修改本机 PATH。示例围绕 Bash/Zsh，不能不加区分地外推到所有 shell 与配置入口。
