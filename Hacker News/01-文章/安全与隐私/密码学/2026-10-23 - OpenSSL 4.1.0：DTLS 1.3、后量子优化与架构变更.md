# OpenSSL 4.1.0：DTLS 1.3、后量子优化与架构变更

<!-- AUTO:BEGIN -->
## 摘要

OpenSSL 4.1.0 是一次功能版本，加入 DTLS 1.3、GREASE、IKEv2 KDF、SSL listener API 的 DTLS 支持和 Elbrus2000 初步支持，同时带来 ML-DSA/ML-KEM NTT 与 AES-CBC 等平台优化。

## 重点解读

- ppc64le 和 x86_64 增加 ML-DSA、ML-KEM NTT 及 SHAKE、AES-CBC 优化，面向后量子算法和硬件指令集。
- 新增 DTLS 1.3、GREASE、DTLS listener API 与 IKEv2 KDF；tsget 改用 Net::Curl::Easy。
- 删除 Windows-on-Itanium、Windows CE 目标，并移除不会真正禁用实现的 no-ecdsa/no-ecdh 配置选项，改用 no-ec。
- 发布说明列出 DTLS 1.3 KeyUpdate、非阻塞 DTLS listener 等已知问题，升级前需要对相关场景做回归测试。
