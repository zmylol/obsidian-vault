# Google AI · 分类规则

按正文主要问题归入唯一的两级类别；跨主题用标签表达，不按模型版本、年份、公司名称或单次事件建类。

| 大类 | 具体分类 | 范围 |
|---|---|---|
| 研究与模型 | 多模态表示 | 多模态编码、嵌入空间、模型结构与检索评估。 |
| Agent 与开发者工具 | Agent 工具链 | Agent、MCP、开发者平台和云端工具调用。 |
| Agent 与开发者工具 | Agent 安全与治理 | Agent 隐私、安全、权限、上下文规范与评测。 |
| 安全与隐私 | 联邦学习隐私 | 联邦学习、可信执行环境、差分隐私与可验证训练。 |
| 科学与应用 | 地理空间健康 | 地理空间基础模型及其在公共健康等领域的应用评估。 |

新增类别前须比较已有边界，确有长期可复用的新范围才登记并同步首页、收录清单和状态。迁移保留来源、日期与个人内容，不自动合并或改名。
