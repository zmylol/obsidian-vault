# GAM：用分层图记忆减少长期交互干扰

<!-- AUTO:BEGIN -->

## 为何入选

GAM 是 ACL 2026 Long Papers 中一篇较新的 Agent 记忆系统工作，针对“新信息要及时吸收、旧知识又不能被短暂噪声污染”的矛盾提出明确的两阶段架构。它把 A-Mem 一类的动态记忆组织进一步拆成事件进展图与主题关联网络，并用语义事件触发合并；同时给出长对话、效率与消融实验，适合观察结构化记忆在近期研究中的演进。

## 摘要

GAM 面向长期对话中的记忆污染，将编码与巩固分开：事件进展图先承接实时对话，语义转折时才写入主题关联网络，读取时融合语义、时间、置信度和角色线索。作者在 LoCoMo、LongDialQA 和四种 backbone 上报告优势，Qwen2.5-7B 的 LongDialQA 平均 F1 为 12.55；附录还用稠密视频字幕做了代理多模态实验。系统仍不支持原生视觉或音频推理。

## 重点解读

### 用事件图承接短期变化

GAM 的 Episodic Buffering Phase 将实时对话写入局部事件进展图，先保留事件之间的顺序和依赖，不立即改写全局知识。这样可以暂时容纳说话人切换或尚未完成的叙事，降低把瞬时信息当作长期事实的风险。

### 语义转折才触发巩固

当检测到语义事件边界时，系统才把局部图整合到 Topic Associative Network。全局网络承载跨主题、跨会话的稳定关系，状态切换机制因此把“写入速度”和“长期一致性”分离。论文的消融显示，去掉 Event Progression Graph 或 State Switching Mechanism 的平均 F1 降幅最大，支持这两个组件的结构性作用。

### 读取时不只看向量相似度

GAM 的 Graph-Guided Multi-Factor Retrieval 将语义匹配与时间、置信度、角色中心性结合，再用图上的跨层关系补回相关上下文。角色线索用于区分多方对话中的同名或相似叙事，时间线索则帮助处理时间敏感的问题。

## 实验与结果

- 论文在 LoCoMo 的前四类问题和 LongDialQA 上比较 MemoryBank、ReadAgent、MemGPT、MemoryOS、Mem0 与 A-Mem。使用 Llama 3.2-3B、Qwen2.5-7B、Qwen2.5-14B、GPT-4o-mini 四个免训练 backbone，GAM 本身不更新模型参数；实验在 RTX 4090 上运行。
- LoCoMo 的 GPT-4o-mini 结果中，GAM 平均 F1/BLEU-1 为 43.14/36.48；作者也报告其在 Qwen2.5-7B 的 Temporal F1 比 Mem0 高 18% 以上，但在 GPT-4o-mini 的 Temporal F1 上 Mem0 仍为 56.42，高于 GAM 的 51.96，说明动态巩固并非所有时间问题都占优。
- LongDialQA 的 Qwen2.5-7B 平均 F1/BLEU-1 为 12.55/12.43，MemoryOS 为 6.76/5.11。效率表中 GAM 每个查询约 1,370 token、0.80 秒、F1 40.00；相较 Mem0 的 1,533.94 token、0.51 秒、F1 35.38，换取准确率的同时略增加延迟。
- 附录 B.4 在 MovieChat-1K 上用稠密视频字幕模拟视觉叙事，Qwen2.5-7B、检索深度 K=15；GAM 相对直接输入基线的 Accuracy/F1/BLEU-1 从 47.35/42.35/45.31 提升到 55.51/48.95/51.63。字幕代理不等于直接读取视频。

## 适用条件与局限

- 核心记忆与主实验是纯文本；附录的多模态结果只把视频转成稠密字幕，不能等同于读取原始视觉或音频，作者仍把原生多模态记忆留给后续。
- LoCoMo 与 LongDialQA 主要是对话问答，开放域问题对 GAM 仍较难，不能代表实时网页、代码、具身或生产工作流。
- 记忆巩固依赖语义转折检测、置信度和角色线索，错误摘要或错误边可能长期存在；论文建议在巩固前加入隐私过滤和用户保留规则。
- 官方 ACL 页面未提供可复现代码链接，本次只依据论文全文复核，没有运行实现。

## 怎样理解与应用（AI 解读）

GAM 提供了一个清晰的工程边界：把“正在发生的事实”放在可回滚的事件层，把“准备长期复用的知识”放在可审计的主题层。部署时可以让事件层承担短期缓存，让巩固任务异步执行，并在写入全局图前做来源、隐私和冲突检查；这样即使巩固失败，也不必污染正在运行的 Agent。这个应用建议是 AI 解读，不是论文额外实验结论。
