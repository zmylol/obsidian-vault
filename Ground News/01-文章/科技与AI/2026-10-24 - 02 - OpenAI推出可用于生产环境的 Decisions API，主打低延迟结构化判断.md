# OpenAI推出可用于生产环境的 Decisions API，主打低延迟结构化判断

<!-- AUTO:BEGIN -->
[返回 Ground News 首页](../../00-首页.md) · [当日完整简报](../../03-简报/2026-10-24%20-%20科技、AI%20与全球要闻每日简报.md)

## 摘要

OpenAI宣布 Decisions API 正式可用，基于 GPT‑6 Luna 处理分类、路由和评分等有界问题，返回概率、选项或分数，而不是完整长文本。官方称其针对这类任务可比 Responses API 快至约 10 倍，并加入 GPT‑Live 原生集成、提示缓存、图片输入、原生 JSON 和单次最多 400 个问题。定价按输入 token 计费，适合把模型放进实时业务决策链路。

## 入选理由

它把模型能力拆成可计量的微型决策服务，可能降低实时代理与工作流的延迟和成本。
