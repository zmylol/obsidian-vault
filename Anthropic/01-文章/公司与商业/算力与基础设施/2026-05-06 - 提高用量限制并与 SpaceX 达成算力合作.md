## 摘要

Anthropic 于 2026 年 5 月 6 日宣布提高用量限制，并与 SpaceX 达成 Colossus 1 算力协议。自公告日起，Pro、Max、Team 及按席位计费的 Enterprise 用户的 Claude Code 五小时额度翻倍，Pro 和 Max 取消高峰时段额度下调，Opus API 的速率限制也提高。公司预计该算力协议在当月带来超过 300 兆瓦容量；轨道算力仅是合作兴趣。额度是当时的安排，协议容量不代表公告当天已经全部上线。

## 重点图文解读

### 额度调整分产品与等级

自 2026 年 5 月 6 日起，Pro、Max、Team 及按席位计费的 Enterprise 计划的 Claude Code 五小时额度翻倍，Pro、Max 取消高峰时段下调；Opus API 按 Tier 分别提高每分钟输入和输出额度。 [原文依据](https://www.anthropic.com/news/higher-limits-spacex)

### 算力落地与远期意向分开

协议涉及超过 300 兆瓦及 超过 22 万颗 NVIDIA GPU，预期月内可用；轨道算力只是表达合作兴趣，尚非已部署能力。 [原文依据](https://www.anthropic.com/news/higher-limits-spacex)

## 适用条件与局限

图中数字是发布当日 API 限额，不能作为永久配额承诺；额度增长也不代表单次请求延迟同比改善。

## 怎样理解与应用（AI 解读）

比较吞吐能力时，应分别测输入、输出和请求并发瓶颈；只提升输入额度，未必能加快输出很长的任务。
