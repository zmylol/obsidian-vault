## 摘要

Anthropic 于 2025 年 12 月 3 日宣布收购 JavaScript 工具链 Bun，目标是加强 Claude Code 的运行、安装和开发基础设施；双方此前已合作改进原生安装器。公告承诺 Bun 继续开源并采用 MIT 许可。公司同时称，Claude Code 在 11 月达到 10 亿美元年化收入运行率，距 5 月正式推出约半年。运行率不是这半年已经取得的累计收入，收购带来的性能收益也尚未通过同条件测试量化。

## 重点图文解读

### Bun 支持开发和分发基础设施

Bun 集运行时、包管理、打包及测试于一体；双方此前合作已用于 Claude Code 原生安装器。 [原文依据](https://www.anthropic.com/news/anthropic-acquires-bun-as-claude-code-reaches-usd1b-milestone)

### 收购后保留开放许可承诺

公告承诺 Bun 继续开源并采用 MIT 许可，持续服务 JavaScript 与 TypeScript 开发者。 [原文依据](https://www.anthropic.com/news/anthropic-acquires-bun-as-claude-code-reaches-usd1b-milestone)
