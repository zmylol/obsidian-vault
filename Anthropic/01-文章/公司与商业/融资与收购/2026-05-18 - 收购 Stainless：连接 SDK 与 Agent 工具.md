## 摘要

Anthropic 于 2026 年 5 月 18 日宣布收购 Stainless，以加强开发者和 AI 代理连接外部系统的工具。Stainless 能依据 API 规格生成软件开发工具包、命令行工具及 MCP 服务，Anthropic 官方开发工具包从 API 早期起已由它生成。此次交易将已有合作纳入同一团队，文章没有宣布新的协议或 API 版本。交易价格、产品迁移时间和外部客户安排未在公告中披露。

## 重点图文解读

### 从 API 规格生成多语言工具

Stainless 依据接口规格生成 TypeScript、Python、Go、Java 等 SDK，也支持 CLI 和 MCP 服务工具。 [原文依据](https://www.anthropic.com/news/anthropic-acquires-stainless)

### 合作早于收购存在

公告说明官方 Anthropic SDK 从 API 早期起已由 Stainless 生成，此次收购把长期工具链合作纳入同一团队。 [原文依据](https://www.anthropic.com/news/anthropic-acquires-stainless)
