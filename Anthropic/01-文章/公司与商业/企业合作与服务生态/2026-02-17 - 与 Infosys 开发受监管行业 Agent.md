## 摘要

Anthropic 与 Infosys 在 2026 年 2 月宣布，将 Claude 与 Infosys Topaz 结合，为电信、金融和制造等行业开发智能体。双方计划用 Claude Agent SDK 支持持续多步任务，以 Topaz 和 Claude 改造遗留系统，另用 Cowork 处理文档与报告。公告称 Infosys 开发者已使用 Claude Code，但更广的行业方案主要仍是开发方向，未披露统一准确率、客户部署规模或独立验证的生产收益。

## 重点文字解读

### 从领域流程选择代理任务

电信侧关注网络运营和客户生命周期，金融侧关注风险与合规流程，制造侧关注设计仿真；这要求领域知识和既有系统接入。 [原文依据](https://www.anthropic.com/news/anthropic-infosys)

### 执行框架承担长任务

双方计划用 Agent SDK 等工具支持持续多步工作，并以 Cowork 处理文档和报告等日常任务。公告称 Infosys 开发者已经使用 Claude Code，但各行业方案的全面交付仍不能据此认定完成。 [原文依据](https://www.anthropic.com/news/anthropic-infosys)
