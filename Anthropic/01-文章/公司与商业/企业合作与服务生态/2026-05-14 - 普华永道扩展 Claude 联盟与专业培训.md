## 摘要

普华永道与 Anthropic 在 2026 年 5 月扩大联盟，将 Claude 用于软件开发、交易执行和企业职能改造，并推出面向客户财务部门的新业务组。双方计划从美国团队推广 Claude Code 与 Cowork，设立联合卓越中心，培训并认证 3 万名美国专业人员，再向全球员工扩展。公告称部分客户项目已投入生产，例如保险核保周期从十周缩短为十天；这些是双方披露的具体案例，不能当作普遍提效保证，也不代表全球推广和培训已完成。

## 重点文字解读

### 组织能力与产品同时扩展

计划从美国团队推广 Claude Code 和 Cowork，设联合卓越中心并培训认证 3 万名美国专业人员，再扩大到全球员工；财务业务组先聚焦银行、保险和医疗。 [原文依据](https://www.anthropic.com/news/pwc-expanded-partnership)

### 案例结果附带部署背景

公告披露保险核保从十周缩至十天、HR 原型一周成形等特定客户案例，并介绍 PwC 自身先试用财务流程的 Customer Zero 做法。 [原文依据](https://www.anthropic.com/news/pwc-expanded-partnership)
