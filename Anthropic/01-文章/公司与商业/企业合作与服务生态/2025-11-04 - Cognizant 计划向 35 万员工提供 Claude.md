## 摘要

Cognizant 在 2025 年 11 月宣布计划向全球最多 35 万名员工提供 Claude，同时把 Claude Code 和智能体工具接入现有工程与交付平台。合作拟覆盖编码、测试和文档工作，分析改造遗留系统，并开发从金融服务起步的行业智能体。多步任务将结合明确策略、审批和人工监督，客户则通过工作坊、参考方案与平台集成推进落地。35 万是计划部署上限，公告没有给出实际使用率或跨项目效果试验，不能据此判断全部员工已采用或生产收益已经实现。

## 重点图文解读

### 开发工具进入现有工程平台

Flowsource 将 Claude Code 用于编写、测试、文档和 DevOps；遗留系统现代化则结合原有迁移框架与代码分析能力。 [原文依据](https://www.anthropic.com/news/cognizant-partnership)

### 多步代理需要显式控制

Neuro 多 Agent 编排与 Agent SDK 组合构建领域代理，公告明确提到策略、审批和人工监督；行业方案先从金融服务开始。 [原文依据](https://www.anthropic.com/news/cognizant-partnership)
