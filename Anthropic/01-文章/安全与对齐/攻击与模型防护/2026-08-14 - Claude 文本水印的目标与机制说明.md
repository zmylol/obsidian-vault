## 摘要

Anthropic 介绍 Claude 文本水印的目标与机制：模型在有多个合适词元时按密钥引导随机选择，留下不可见的统计模式，不添加隐藏字符、额外词元或用户身份信息。检测结果只能估计 Claude 参与的可能性，短文本、代码、事实性文字和重写会降低可检出性，检出或未检出都不能证明作者身份或排除其他模型。文章另将文本水印与文件的 C2PA 凭证区分，并称检测 API 已向符合条件的机构开放私有预览；这些安排不等于法律或版权结论。

## 重点文字解读

### 水印改变的是等价表达的随机选择

所用方法基于 SynthID-Text：在多个合适词元之间选取时引入可检测模式。固定事实和必须精确的代码选择空间较小，因此水印较稀疏。 [原文依据](https://www.anthropic.com/news/claude-text-watermark)

### 检测只能提供有限的来源证据

短文本、轻度润色和大量改写会降低检测能力；检测不到不证明是人写，检测到也不能区分完整生成与重度编辑。它不能识别采用其他密钥的模型。 [原文依据](https://www.anthropic.com/news/claude-text-watermark)

### 文本与文件凭证是两套机制

支持的图片等文件使用 C2PA 签名元数据记录 Claude 参与情况。9 月 1 日更新说明文本检测 API 为符合条件机构的私有预览，旧模型水印仍分阶段推进。 [原文依据](https://www.anthropic.com/news/claude-text-watermark)
