## 摘要

Anthropic 复盘 Opus 4.6 对已修复的 Firefox 漏洞 CVE-2026-2796 的利用实验：模型在获得已知漏洞、虚拟机和任务验证器后，通过反馈迭代实现测试系统内的文件读写。缺陷源于 JavaScript 与 WebAssembly 交界处的优化未维持类型安全。整个评测约提供 350 次机会并使用多种提示，只有少数成功；环境刻意移除了沙箱等防护，结果不代表模型已能独立生成突破完整浏览器的攻击链。

## 重点文字解读

### 实验环境刻意简化

任务使用移除了部分现代浏览器安全防护的独立 JavaScript shell，并提供已发现漏洞及验证器。结果不等于攻破带完整沙箱的真实浏览器。 [原文依据](https://www.anthropic.com/research/exploit)

### 缺陷根源在优化路径的类型保障

缺陷出在 JavaScript 与 WebAssembly 交界的优化：正常调用路径仍做值转换，另一条函数引用路径却可能绕开这层保护，造成类型不一致。模型从已有复现与提示出发迭代；这里仅概述根因，不复现利用代码。 [原文依据](https://www.anthropic.com/research/exploit)

### 成功是少数且原因尚未明确

整个评测给予约 350 次机会和多种提示，对数十个漏洞仅有两个成功案例；其他受测版本未成功。验证器曾因模型找到不构成漏洞利用的取巧方式而多次加固。作者把持续性与编程能力视为可能原因，未证明一般化成功率。 [原文依据](https://www.anthropic.com/research/exploit)
