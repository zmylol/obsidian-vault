# 解耦代理执行、工具环境与会话状态

## 摘要

Anthropic 的 Managed Agents 将持久会话日志、调用模型的运行循环和执行代码的沙箱拆成可替换组件，避免一个容器故障同时丢掉控制进程与会话状态。运行循环可从独立事件日志恢复，沙箱则按需建立并作为工具调用，完整会话历史也不再等同于模型当前能看到的上下文。公司报告，这一架构让其系统首个输出 token 的等待时间中位数降低约 60%，第 95 百分位降低超过 90%。收益来自该托管系统的改造，不能直接当成所有应用的提速保证。

## 重点文字解读

### 耦合容器难以恢复和排障

会话、控制循环与用户代码放在同一容器时，一次故障可能同时丢掉工作状态与诊断入口。

### 会话日志与执行环境分离

事件日志保留完整历史；运行框架按需读取，而不是把当前上下文窗口当成全部会话。沙箱通过工具接口调用。

### 按需配置减少启动等待

无需立即使用沙箱的任务可先推理。作者报告首 token 延迟的中位数下降约 60%，p95 下降超过 90%。

## 适用条件与局限

性能收益来自该托管系统的架构变化，不保证任意应用有同样提升；图中接口是设计说明，不应当作正式 SDK 签名。

## 怎样理解与应用（AI 解读）

检验自己的长任务系统时，可以在保存事件后终止执行进程，再确认新进程是否知道最后完成哪一步、哪些动作尚未确认。把可恢复日志与压缩后的模型上下文分别保存。
