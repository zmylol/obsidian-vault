## 摘要

Anthropic 于 2025 年 11 月宣布 Claude 进入 Microsoft Foundry 与 Microsoft 365 Copilot。Foundry 以 serverless 方式提供模型公共预览并沿用 Azure 采购与认证；Copilot Studio、Researcher 和 Excel Agent Mode 面向 Microsoft 业务入口。Global Standard 先上线，US DataZone 尚待推出；这是可用性公告，没有统一成功率或独立对照。

## 重点文字解读

### Foundry 降低采购与接入成本

首批公共预览包括 Sonnet 4.5、Haiku 4.5、Opus 4.1，以 serverless 方式部署，支持既有 Azure 协议、MACC 和 Entra 认证；首发为 Global Standard，US DataZone 仍待推出。 [原文依据](https://www.anthropic.com/news/claude-in-microsoft-foundry)

### Copilot 场景与模型调用入口不同

Claude 可用于 Researcher、Copilot Studio，自 Excel Agent Mode 预览起还可生成公式、分析数据和修改表格。Foundry 则面向开发者的 API、SDK 与生产应用。 [原文依据](https://www.anthropic.com/news/claude-in-microsoft-foundry)
