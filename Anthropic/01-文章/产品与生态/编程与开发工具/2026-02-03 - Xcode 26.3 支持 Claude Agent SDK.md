## 摘要

Anthropic 于 2026 年 2 月宣布 Xcode 26.3 原生集成 Claude Agent SDK，使 Claude 从逐轮助手扩展为可在 IDE 内运行子代理、后台任务和插件的长期代理。它能浏览项目结构、查询 Apple 文档、修改多个文件，并通过 Previews 观察 SwiftUI 界面后迭代；同一能力也可经 MCP 供终端 Claude Code 调用。发布时仍是候选版本，视觉预览不替代真机、性能与无障碍测试。

## 重点文字解读

### 预览让界面实现形成反馈闭环

Claude 可截取 Xcode Previews，检查 SwiftUI 视觉结果并迭代；同时探索完整项目结构，结合 Apple 文档理解框架后再修改。 [原文依据](https://www.anthropic.com/news/apple-xcode-claude-agent-sdk)

### SDK 与 MCP 提供不同接入方式

IDE 内 SDK 支持子代理、后台任务和插件；Xcode 的 MCP 接口也允许终端中的 Claude Code 使用其能力并获取预览。发布日 Xcode 26.3 仍为开发者 RC。 [原文依据](https://www.anthropic.com/news/apple-xcode-claude-agent-sdk)
