## 摘要

Anthropic 于 2026 年 5 月发布十个金融服务代理模板，把业务指令、受控数据连接和专门处理子任务的代理组合起来，用于估值、对账、客户审查等工作。付费用户可在 Cowork 或 Claude Code 中使用插件，也可通过仍在公测的 Managed Agents 持续执行任务，向客户发送或采取行动前须人工审核。公告还扩展 Microsoft 365 协作和金融数据连接；Outlook 当时尚未正式推出，客户评价不能代替独立效果验证。

## 重点图文解读

### 十个模板覆盖研究与运营

包括路演材料、会议准备、财报复核、建模、市场研究，以及估值复核、总账对账、月结、报表审核和 KYC 筛查。企业可按内部建模规范与风险流程调整。 [原文依据](https://www.anthropic.com/news/finance-agents)

### 桌面协作与托管运行两种形式

模板可作为 Cowork、Claude Code 插件运行，也可用 Managed Agents cookbook 执行长任务，配合逐工具权限、凭据保管与审计日志。输出交给客户、提交或实际执行前由用户审核。 [原文依据](https://www.anthropic.com/news/finance-agents)

### 跨应用上下文减少重复解释

Excel、PowerPoint 与 Word 插件已可用，Outlook 在文中仍是即将推出。新增数据伙伴连接器与 Moody’s MCP app，分别提供受控数据和内嵌交互界面。 [原文依据](https://www.anthropic.com/news/finance-agents)

## 适用条件与局限

Opus 4.7 的 Finance Agent 64.37% 是指定基准分数。产品模板与客户评价不等同财务、审计或合规结论的保证。

## 怎样理解与应用（AI 解读）

金融自动化应围绕可追溯输入、明确审批点和工具调用日志设计；先让代理完成准备与核对，再评估是否适合扩大自主执行范围。
