# 经济指数报告：地域与企业 AI 采用差异

## 摘要

报告把 Claude.ai 对话与第一方 API 使用放在同一框架中，比较任务变化、150 多个国家及美国各州的使用强度，并分析企业 API 部署。编程仍约占 Claude.ai 样本 36%，教育任务由 9.3% 升至 12.4%，科学任务由 6.3% 升至 7.2%；指令式完整委派由 27% 升至 39%。AUI 与收入强相关，新加坡约 4.6 倍、印度约 0.27 倍；第一方 API 企业自动化约 77%。这些是 Anthropic 产品样本的相关观察，不能证明收入造成采用或岗位替代。


## 重点图文解读

### 任务分布在扩展，不能只看编程

与年初相比，教育和科学相关任务占比上升，但计算机与数学任务仍约占三分之一。这里统计的是样本对话对应的任务份额，份额下降不一定意味着该用途的绝对使用量下降。 [原文依据](https://www.anthropic.com/research/anthropic-economic-index-september-2025-report)

### 直接委派增加，但不等于岗位消失

Claude.ai 中直接委派整项任务的对话从约 27% 升至 39%；API 的自动化模式约占 77%。交互方式反映流程组织，不能直接换算成被替代的劳动者人数。 [原文依据](https://www.anthropic.com/research/anthropic-economic-index-september-2025-report)

### 地区比较需要按人口校正

AUI 用某地使用份额除以其劳动年龄人口份额，区分市场总量和相对普及程度。跨国使用与收入相关，国内任务组合还与当地行业结构有关；这些是相关关系，不能单凭图表识别因果。 [原文依据](https://www.anthropic.com/research/anthropic-economic-index-september-2025-report)

## 适用条件与局限

数据只覆盖指定 Claude.ai 与第一方 API 样本，不能代表全球全部 AI 使用。地理定位、职业映射、产品更新与用户构成变化都会影响比较，企业平台的调用也不一定对应完整工作。

## 怎样理解与应用（AI 解读）

可以把这份报告作为年度基线，分别追踪任务类型、协作方式、地区普及，而不要用单一使用量排名判断一个国家或行业的 AI 成熟度。
