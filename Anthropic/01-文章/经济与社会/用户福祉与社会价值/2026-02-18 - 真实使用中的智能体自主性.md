# 真实使用中的智能体自主性

## 摘要

Anthropic 用 2025 年末至 2026 年初的 Claude Code 会话和公共 API 工具调用研究实际自主性。Claude Code 轮次时长的第 99.9 百分位数曾从不足 25 分钟增至超过 45 分钟，但中位数仍约 45 秒；经验更多的用户既更常自动批准，也更常主动中断，模型还会停下请求澄清。API 样本中多数动作被判为低风险且可逆，但单次调用看不到完整任务链，也未区分生产操作与评估。结果显示监督方式与运行时长需一起观察；它们来自单一提供商的观察数据和模型分类，不能视为所有智能体的能力或安全保证。

## 重点图文解读

### 增长主要出现在运行时间分布的尾部

Claude Code 轮次时长的中位数约 45 秒；第 99.9 百分位数，即约 99.9% 轮次不超过的时长，从 2025 年秋季不足 25 分钟上升到 2026 年 1 月超过 45 分钟，随后有所回落。图中展示的是高分位数的滚动统计，不能解读成每次任务平均运行 45 分钟。 [原文依据](https://www.anthropic.com/research/measuring-agent-autonomy)

### 熟练用户同时增加授权与主动监督

过去使用次数更多的用户，更常启用完全自动批准；完全自动批准的会话占比，在少于 50 次历史会话的用户中约为 20%，到 750 次左右时超过 40%。按轮次统计的中断率则从新用户的约 5% 增至较熟练用户的约 9%；两者分母不同。两种行为并存，更像是选择何时介入，而不是简单放弃监督。 [原文依据](https://www.anthropic.com/research/measuring-agent-autonomy)

### 真实使用中的自主性是多种因素共同形成的

复杂任务中，智能体主动请求澄清比用户中断更常见，但这并不证明每次暂停都正确。模型能力、任务类型、Plan 模式、产品设计和用户经验都会影响表现；API 数据还无法像 Claude Code 那样完整重建所有智能体任务链。 [原文依据](https://www.anthropic.com/research/measuring-agent-autonomy)

### 工具调用样本没有展示完整部署

公共 API 样本中多数动作被模型判为低风险、可逆，软件工程约占工具调用的一半。但调用次数多的工作会被更多采样，无法据此计算部署数量；模型也无法区分生产、模拟及红队评估，部分高风险簇可能就是测试。 [原文 Agents are used in risky domains；Limitations](https://www.anthropic.com/research/measuring-agent-autonomy)

## 适用条件与局限

运行时长只是自主性的代理指标，不能与按人类完成时间计算的能力评估直接等同。数据来自特定产品和用户，风险评分也依赖模型判断；隐私阈值会排除部分罕见任务，不能用总体低风险推断罕见高风险不存在。

## 怎样理解与应用（AI 解读）

设计自己的定时知识库任务时，可以按可逆性配置权限：搜集和生成草稿允许自动进行，涉及覆盖个人笔记或对外发送时设置明确边界。记录任务时长、主动澄清和人工中断，比只记录“跑了多久”更能帮助判断自动化是否可靠。
