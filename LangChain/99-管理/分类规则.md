# LangChain · 分类规则

按正文的主要问题归入唯一类别，跨主题用标签表达；不按模型版本、年份、公司名称或一次事件拆分类。以下只登记已有文章的类别，不设学习路线。

| 大类 | 具体分类 | 范围 |
|---|---|---|
| 工程与Agent | 上下文管理 | 进入模型的信息选择、压缩与隔离；不包含部署服务。 |
| 工程与Agent | 运行架构 | 执行框架、解释器及状态组织；多 Agent 分工归多智能体协作。 |
| 工程与Agent | 多智能体协作 | 子任务分工、同步异步执行与协作；通用评估另归评估与可靠性。 |
| 工程与Agent | 评估与可靠性 | 任务验收、基准、测试与复现条件。 |
| 工程与Agent | 部署与持久化 | 运行服务、部署接口与跨运行数据保存。 |

新增类别先比较已有边界，确有不同且可长期复用的范围才登记；同步更新目录、首页、清单、状态及原文链接。迁移保留来源、日期、个人阅读记录与个人内容，已有分类不自动合并或改名。
