# Numan 用评估优先的 AI 健康教练守住医疗边界

## 摘要

Numan 介绍了 Nu 这款面向长期健康管理的 AI 教练，并把重点从“让 Agent 回复得像教练”转向定义可检验的评估标准。团队让固定数据集负责单条回复的路由、用药安全和教练质量，再用生成式患者模拟多轮对话，评估整段交流是否追问充分并守住不诊断、不处方的边界；所有评估都经过真实 LangGraph 图并由 LangSmith 记录。文章称，临床专家签署的评分标准才可作为安全发布门槛，模拟对话层在临床签署前仍是原型，案例结果不能外推为普遍医疗安全结论。

## 重点图文解读

### 固定数据集只覆盖单条回复能证明的行为

Numan 先用单轮固定样本和 LLM 裁判评估 Nu，但发现健康教练的安全性取决于对话上下文；预先写死的多轮脚本又会忽略 Agent 实际回复后用户应如何反应。最终方案把路由、用药问题、安全守卫和教练质量拆成按类别评分的主题数据集，并让每个评分标准只判断一条回复可显示的内容，避免平均分掩盖某一类严重失败。

### 真实 LangGraph 图就是评估对象

Nu 由 supervisor 协调多个领域子 Agent，每个子 Agent 有自己的提示和工具。评估不复制提示词另建 harness，而是调用患者实际使用的同一张图；因此可以把整套数据集切换到不同模型供应商并进行并排比较。文章把“发布的东西就是测试的东西”作为减少生产与测试漂移的原则，但没有提供跨团队的受控效果实验。

### 用安全守卫和临床标准把边界变成发布门槛

每次改动都运行医疗安全探针，回归会阻止发布；图中的 guard node 会在回复发送前检查固定临床规则，不安全时交回 supervisor 重生成，连续失败则替换为安全兜底。健康教练还每天抽查真实对话。文章强调，工程师可先起草标准，但涉及安全或医疗范围的 rubric 必须由理解监管边界的临床专家签署，未签署的模拟结果不能支持安全声明。

### 生成式患者模拟多轮对话

文章最新的原型层不再预写患者后续回复，而是给出患者人格、场景、应被引出的关键问题和轮数上限，由更便宜的模型扮演患者并对 Nu 的实际说法作出反应，再由裁判按类别评分整段 transcript。这样可以探测诱导越界或伪装成普通问题的攻击性措辞；但文中明确指出，missed-dose 等规则可能互相冲突，模拟层在临床签署 rubric 前不用于放行或安全声明。

## 适用条件与局限

固定样本适合检查单条回复可观察的行为，多轮模拟才有机会覆盖依赖上下文的教练质量，但生成式患者和裁判本身会引入模型偏差。文章是 Numan 的案例自述，没有给出完整样本、统一准确率或成本对照；“一日完成供应商迁移”来自其内部经验。Nu 被设计为健康教育与生活方式教练，不诊断、开处方、监测疾病或作临床决策；临床专家未签署的 rubric 不能支撑安全结论。

## 怎样理解与应用（AI 解读）

**AI 解读：** 对需要守住监管边界的 Agent，可先把单条回复的确定性检查和整段对话的行为检查分层，再让所有测试穿过生产使用的同一工作流。每条 rubric 应写清可观察证据、失败类别和放行条件；模拟患者只能扩展探索范围，不能替代领域专家对安全标准的签署。这是根据原文案例抽象出的实施建议，不是 Numan 的额外实验结论。
