# 让 Agent 在授权预算内购买服务并追踪付款

## 摘要

Nevermined 与 LangChain 的合作教程展示了 Agent 在任务中购买服务的流程：人先授权支付方式并设定限额，研究 Agent 随后可购买搜索额度、耗尽后充值，或接入新的数据服务。按作者说明，预算和期限等限制由服务端执行，授权能随任务传给子 Agent，约束整个任务分支的花费。商家也可给工具接口加上按次收费保护，把验证和结算记录接入 LangSmith。这些示例依赖相应支付集成和商家支持，不能据此推定任意服务都能自动购买。

## 重点文字解读

### 把支付授权变成可执行限额

用户先完成卡片授权；预算、期限、单次额度和交易次数由服务端在付款前检查。额度耗尽后可在授权范围内充值。

### 付费工具可以放在子 Agent 内

商家给接口加 requires_payment 保护，按调用收费；支付上下文随 task() 传下一层，预算约束整体分派。

nvm.verify 与 nvm.settlement 进入工具调用的追踪树，能关联购买和产出；是否值得花这笔钱仍需另评结果质量。

## 适用条件与局限

只节选工程集成，不采用市场规模预测。支付代码、授权窗口与交易均未由本次维护实际运行；示例商家支持不代表普遍兼容。

## 怎样理解与应用（AI 解读）

**AI 解读：**可先用模拟账本测试额度不足、授权过期、重复请求和并行子任务，验证总预算没有被按子任务重复放大，再考虑真实交易。
