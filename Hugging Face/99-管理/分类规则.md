# Hugging Face · 分类规则

按正文的主要问题归入唯一类别，跨主题用标签表达；不按模型版本、年份、公司名称或一次事件拆分类。以下只登记已有文章的类别，不设学习路线。

| 大类 | 具体分类 | 范围 |
|---|---|---|
| 工程与Agent | 记忆与上下文 | 跨会话证据、记忆保存与上下文检索；通用文档搜索归检索系统。 |
| 模型训练 | 任务微调 | 模型训练数据、奖励与训练后评估；仅改索引不归本类。 |
| 推理与部署 | 本地推理 | 浏览器或本地硬件上的算子、运行时与推理性能；训练另归任务微调。 |
| 数据与检索 | 检索模型训练 | 检索表示的领域训练与独立评估；不改模型的索引实现归检索系统。 |
| 数据与检索 | 检索架构 | 表示与评分方法的原理及选型；训练和部署细节分别归专门类别。 |
| 开源生态 | 生态观察 | 开放模型分发、使用与衍生开发的统计；个人模型实验归各来源的实测类。 |
| 应用实践 | 可视化工作流 | 图形化节点编排、调试和应用交付；通用 Agent 执行机制归执行架构。 |
| 数据与检索 | 检索系统 | 索引构建、版本契约、混合召回与在线查询；向量压缩细节归检索效率。 |
| 工程与Agent | 执行架构 | Agent 如何表达动作与控制流程；跨会话记忆另归记忆与上下文。 |
| 数据与检索 | 检索效率 | 向量压缩、存储和检索成本；模型训练与通用评分原理另归对应类别。 |

新增类别先比较已有边界，确有不同且可长期复用的范围才登记；同步更新目录、首页、清单、状态及原文链接。迁移保留来源、日期、个人阅读记录与个人内容，已有分类不自动合并或改名。
