# 把 Agent 会话变成可追溯记忆

## 摘要

Funes 把多种编程 Agent 的会话统一为本地可检索记忆，结合向量与关键词检索返回原始片段、出处及上下文，避免只留下压缩结论。用户可选择把记忆同步到自己拥有、默认私有的 Hugging Face 数据集，以便跨机器使用。作者在两项依赖旧会话信息的任务中报告，检索方式每次成功任务的加权 token 成本分别约为书面交接的八分之一和四分之一，已计入一次性准备开销。这只是两个任务的结果，不能当作普遍节省比例；本地检索与远程同步也是不同的使用方式。

## 重点文字解读

### 保留证据片段

会话先统一为轮次与内容块，再分块建索引；检索返回原始对话并允许展开上下文，减少只保存浓缩结论造成的信息丢失。

### 组合检索信号

向量与 BM25 召回结合重排序、时间信号和相邻片段，既找近义表达，也保留精确术语。默认本地保存，远端同步是可选行为。

### 用任务成本检验记忆

文中的两项既有知识任务比较了 recall、压缩和交接方式；这些小样本结果说明值得测量准备成本，不能证明所有任务都会省钱。

## 适用条件与局限

效果依赖会话质量和检索命中；脱敏不能保证清除所有敏感信息。作者的两任务实验不构成通用效率基准。

## 怎样理解与应用（AI 解读）

知识库可以保留每条结论对应的原文段落、日期和链接；以后检索失败时，先检查证据是否保存，再考虑增加总结层。
