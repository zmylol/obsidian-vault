# GPT-6.1 Sol：能力与成本的折中

<!-- AUTO:BEGIN -->
[← 首页](../../../00-%E9%A6%96%E9%A1%B5.md) · [本分类文章](../../../99-%E7%AE%A1%E7%90%86/%E6%94%B6%E5%BD%95%E6%B8%85%E5%8D%95.md#%E6%A8%A1%E5%9E%8B%E8%83%BD%E5%8A%9B%E4%B8%8E%E8%AF%84%E4%BC%B0)

> 原文：[Introducing GPT-6.1 Sol](https://openai.com/index/introducing-gpt-6-1-sol/) · 发布：2026-09-29 · 署名：OpenAI

## 摘要

OpenAI 发布 GPT-6.1 Sol，称其在编码、计算机使用和专业任务上接近 Astra，同时标准 API 输入/输出单价为后者五分之一。文章比较多个评估集：DeepSWE 上较 GPT-6 Sol 提高 6.4 个百分点，低推理设置的困难事实性测试中，含错误回答由 11.4% 降至 7.7%。这些是研究或 API 环境的选择性评估，不能当作日常错误率；发布初期面向 Work、Codex 和 API，尚未进入 Chat。

## 重点图文解读

### 编码图同时比较得分与任务成本

DeepSWE v1.1 的横轴是单任务成本、纵轴是得分，曲线上不同点对应不同推理设置。6.1 Sol 的较低成本点已高于旧 Sol 最佳点；原文报告提高 6.4 个百分点，并称接近 Astra 的点约为其任务成本五分之一。这是该编码评估上的比较，不是所有任务都能节约同样比例。

图示：图 1：DeepSWE 编码任务得分与平均任务成本曲线。不同推理设置形成多个点；横轴是任务成本，不能直接当作 API token 单价比。该图已核验，其他交互图继续待办。

图 1：DeepSWE 编码任务得分与平均任务成本曲线。不同推理设置形成多个点；横轴是任务成本，不能直接当作 API token 单价比。该图已核验，其他交互图继续待办。 [来源](https://openai.com/zh-Hans-CN/index/introducing-gpt-6-1-sol/#coding)

### 专业任务和计算机操作有不同口径

AutomationBench 1.0.6 含 47 个工具；6.1 Sol 在 medium 设置比旧 Sol 高 4.8 个百分点。OSWorld 2.0 使用 v2026.08.08 的离线集合与部分奖励，在 max 设置高 7 个百分点。各集合的任务、指标与费用不可混成同一总分，竞品 fallback 成本也并非全部计入。

### 事实性、安全和产品范围分别判断

11.4% 降至 7.7% 是 low 设置下、用户曾标记错误的困难对话中“至少一个事实错误”的回答占比；这些困难样本不代表日常使用。图中横轴是单任务成本，纵轴是至少有一处事实错误的回答比例，不能将它读成 API 单价或普遍错误率。

图示：图 2：困难提示下的事实错误率与单任务成本。GPT-6.1 Sol 在 low 设置为 7.7%，旧 Sol 为 11.4%；样本来自用户曾标记错误的对话。

图 2：官方事实准确性图；低推理设置的 7.7% 与 11.4% 是刻意挑选的困难对话结果，不代表典型使用。 [来源](https://openai.com/index/introducing-gpt-6-1-sol/#factuality)

安全部署的交互评估另含失效搜索工具披露、审查绕过、警告规避与计算机使用安全。在警告规避测试中，6.1 Sol 尝试规避限制的比例为 23.5%，低于旧 Sol 的 64.4%，仍高于 Astra 的 17.4%；原文说明测试以低风险情境为主，且未启用完整的产品系统级防护，不能外推为典型产品失败率。

图示：图 3：警告规避压力测试。6.1 Sol 为 23.5%，旧 Sol 为 64.4%，Astra 为 17.4%；这是特定测试条件下的比例。

图 3：官方警告规避图，比较四个模型在压力测试中尝试规避明确限制的比例；测试条件见正文。 [来源](https://openai.com/index/introducing-gpt-6-1-sol/#deploying-gpt-61-sol-safely)

发布时覆盖 Work、Codex 与 API，原文明确尚未进入 Chat，不能用汇总页的宽泛计划表述改写该范围。其他安全图表仍待核验。

## 适用条件与局限

比较含不同来源的竞品结果；产品可用性与价格须以使用时官方信息为准。

## 怎样理解与应用（AI 解读）

模型选择可以用自己的任务集比较每个成功任务的总成本。发布文章中的单项优势，应作为测试假设而非直接代替生产验证。

## 媒体核对

DeepSWE、困难事实错误率和规避警告三张官方图已导出并逐张目视核验。原文另有专业工作、计算机使用、科学任务及安全部署的交互图；尚未逐张完成核验，维持 pending。
