# Dots：持续工作的个人 Agent 与权限边界

## 摘要

OpenAI 发布 Dots：由 Astra 驱动、拥有云端计算机的持续工作 Agent，可通过连接的应用和聊天渠道协作，并接受反馈。文章区分后台“主动研究”的只读工具与用户任务中的执行能力，配有自定义规则、动作审查及监控暂停。发布初期面向符合地区条件的 Pro、Business Premium，企业需管理员开启测试；委派到 Work/Codex 的任务仍计入相应额度。能力和开放范围是发布方说明，尚需实际任务检验。

## 重点图文解读

### 持续工作依赖连接与上下文

Agent 使用自己的云端电脑和已连接应用，用户可查看工作。

### 主动研究只读

后台发现线索与执行用户任务具有不同操作边界。

### 权限与用量分别管理

动作审查、自定义规则、管理员开启和任务额度都影响可用性。

## 适用条件与局限

常驻能力不等于无限额度或无须审批；企业专职 Dots 仍为定向试点。

## 怎样理解与应用（AI 解读）

采用持续协作 Agent 时，可先定义它长期关注的目标和交付标准，再明确可自行执行及需要复核的动作。这样才能评估它是否减少协调负担。
