# OpenAI 对欧盟文本来源规则的处理方案

<!-- AUTO:BEGIN -->
[← 首页](../../../00-%E9%A6%96%E9%A1%B5.md) · [本分类文章](../../../99-%E7%AE%A1%E7%90%86/%E6%94%B6%E5%BD%95%E6%B8%85%E5%8D%95.md#%E6%96%87%E6%9C%AC%E6%9D%A5%E6%BA%90)

> 原文：[Our approach to EU text provenance rules](https://openai.com/index/eu-text-provenance/) · 发布：2026-10-05 · 署名：OpenAI

## 摘要

OpenAI 公布 textGrain 文本水印方案：全球 API 客户可为部分模型选择开启，欧盟符合条件的 ChatGPT 与 Codex 输出则逐步加入水印，检测器先开放给获批研究机构。水印是在词语选择中嵌入统计信号。公司在目标误报率 1% 的测试中发现，检测受文本长度和领域影响；400-token 英文段落改写 25% 的词时，检测率从约 92% 降至 17%。水印不能证明事实准确或认定作者。

## 重点图文解读

### 产品与地区分阶段开放

API 为部分模型提供全球选用，默认关闭；符合条件的欧盟 ChatGPT 与 Codex 输出将在数周内加水印。检测器初期仅面向获批研究者与专业机构，并非所有用户均可使用。

### 长度与领域改变检测率

下图来自 ELI5 数学和心理学问题，目标误报率为 1%。200/400 token 时，数学检测率为 36.5%/60.8%，心理学为 78.5%/94.3%。两组采样口径不同：数学每题一条回答，心理学每题十条并汇总；分母也随长度资格改变。不能把领域差异解读成所有文本的固定准确率。

### 编辑会削弱统计信号

编辑实验使用同一池 600 条英文回答，分别确定各条件的长度资格。在 400 token 时，未编辑为 91.96%，替换 10%/25% 词语后为 65.79%/17.24%。这一图的未编辑基线来自另一实验池，不能与上图心理学的 94.31% 直接混算。

图 2：同义词替换削弱水印，400 token 的检测率由约 92% 降至约 66% 或 17%。三个条件沿用原始 600 条回答池，长度资格分别确定。 [来源](https://openai.com/index/eu-text-provenance/#how-our-watermarking-works-and-performs)

### 输出质量与检测边界

公司对 Astra/max 的基准对照未发现有意义的总体质量差异，但单项有升有降，不能称完全不影响任何任务。水印不识别用户、不认定权利责任或内容真伪；短文、编辑、翻译及不支持的模型都可能造成漏检。

## 适用条件与局限

这里总结公司公布的方案和实验，不能将受控检测率推广到所有文本，亦不构成合规判断。

## 怎样理解与应用（AI 解读）

来源信号适合帮助透明度核查。实际系统应把它与版本记录、内容凭证及其他证据一起解释，避免由单个检测分数直接推断作者责任。
